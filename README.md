# PATRIX

**Niemiecka jakość na co dzień.** Sklep internetowy z oryginalnymi produktami z Niemiec (rynek polski, PLN).

- `apps/backend` — Medusa v2: commerce, panel administracyjny, role pracowników, audyt, MFA
- `apps/storefront` — Next.js 16: sklep z design systemem PATRIX
- `infra` — Docker Compose i Caddy
